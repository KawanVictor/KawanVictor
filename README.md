Projetos em destaque
🖥️ PC Control Center · ⬇ baixar

Central do Windows para monitorar e ajustar o computador com dados reais: CPU, RAM, GPU, discos e temperaturas em tempo real, rede e Wi-Fi com ping, teste de velocidade e descoberta dos aparelhos conectados, alertas com limite e duração mínima, relatórios, 20 widgets de área de trabalho e cenários de um clique. Python PySide6 (Qt 6) APIs do Windows · cerca de 22 mil linhas · segurança documentada requisito a requisito (backup do Registro com desfazer, nenhum comando via shell, assinatura digital conferida antes de rodar ferramentas baixadas) · CI com ruff, mypy e 4 baterias de testes · dependências travadas · instalador sem administrador
